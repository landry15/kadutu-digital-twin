# python -m app.services.excel_service
#       ce commande permet de créer la base de données SQLite et d'importer les données du fichier Excel dans les tables correspondantes. Assurez-vous que le fichier Excel est correctement formaté et placé dans le répertoire approprié avant d'exécuter cette commande.

# python -m app.services.geo_service 
        ça permet de generer le fichier GeoJSON à partir des données de la base SQLite. Assurez-vous que la base de données est correctement configurée et que les tables contiennent les données nécessaires avant d'exécuter cette commande.
